# OrbitalX Brand Guidelines

## Identity
- **Application Name:** OrbitalX
- **Tagline:** Explore. Monitor. Command.

## Logo
- Must contain an orbit ring, a small satellite, and the "OrbitalX" wordmark.

## UI Design System
- **Style:** DARK COSMIC MISSION CONTROL
- **Atmosphere:** Modern Mission Control + 3D Space Visualization + Professional Data Dashboard
- **Colors:** Black, Deep navy, Cyan, Blue, Violet, Green, Amber, Red, Gray
- **Visual Elements:**
  - Glassmorphism
  - Thin borders
  - Subtle glow
  - Starfield
  - Orbital lines
  - Technical UI
  - Modern typography
  - Monospace telemetry values

## What to Avoid
- Cartoon design
- Excessive neon
- Generic SaaS appearance
- Cryptocurrency dashboard style
- Gaming UI

The design should look professional rather than overly futuristic or flashy. It must be responsive across desktop (1920x1080 primary), laptop (1440x900, 1366x768), tablet, and mobile (collapsible sidebar, hamburger menu, responsive tables/charts/3D).
